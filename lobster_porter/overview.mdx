# 龍蝦搬運工（lobster_porter）

龍蝦搬運工是一套可擴展的批量檔案搬運、整理、分類與自動標注工具，專為大型多媒體製作（如電影、動畫、廣告）的資料管理流程而設計。

## 核心設計原則

- **策略模式（Strategy Pattern）**：所有搬運、分類邏輯皆可替換或組合，滿足不同製作部門需求。
- **插件化（Plugin Architecture）**：透過插件擴展自動處理邏輯，無需改動核心 codebase。
- **可撤銷操作與日誌**：每次批量操作均記錄 log，支援單步撤銷，保障製作素材安全。
- **CLI 優先**：所有功能以命令列介面驅動，方便整合進 CI/CD 或製作自動化管線。

## 已實作模組（截至目前）

<CardGroup cols={2}>
  <Card title="批量移動與複製" icon="arrows-up-down-left-right">

  <Card title="基礎 CLI 介面" icon="terminal">

## 架構示意

```
lobster_porter/
├── core/
│   ├── mover.py          # 批量移動 / 複製引擎
│   ├── classifier.py     # 分類策略主控器
│   └── tagger.py         # 標籤管理器
├── plugins/
│   ├── base_plugin.py    # 插件抽象基類
│   └── examples/         # 範例插件
├── cli/
│   └── main.py           # CLI 入口
├── logs/
│   └── operation_log.py  # 操作日誌與撤銷系統
└── tests/
    └── ...               # 單元測試與整合測試
```
