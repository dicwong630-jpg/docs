# 10句高密度輸入引導框架

> **核心原則**：一個有文采的創作者，一句說話可以表達好多嘢。呢個框架就係要將「有意思的一句說話」拆成10個引導位，讓任何用戶都能輸出同等密度的信息。AI負責補充文采、建立脈絡、生成有紋理有脈搏的視頻。

---

## 為什麼需要引導框架？

| 問題 | 解釋 |
|------|------|
| 用戶唔係作家 | 大部分人有故事想說，但唔知點組織成劇本 |
| AI需要信息密度 | 「講個故事」太籠統；10條問題的回答 = 可操作的劇本骨架 |
| 分層渲染的基礎 | 10個引導位直接對應場景切割點 → 駁口 → 渲染指令 |

---

## 10個引導位（Frame 1–10）

### Frame 1：現在在哪？

> 主角現在係咩地方、咩時間？呢個空間有咩氣氛？

**例子**：
- 「夜晚12點，KO仔喺機房入面，冷氣開到最大，到處都係顯示器」
- 「清晨，大師姐企喺擂台邊，觀眾未入場，場地空蕩蕩」

**分層渲染對應**：背景 Layer — 場景定格，首幀靜態建立。

---

### Frame 2：主角嘅心理狀態

> 主角而家嘅情緒係？佢係放鬆定緊張、自信定迷茫、開心定壓抑？

**例子**：
- 「KO仔係既興奮又驚，因為佢而家要用 AI 備戰明日嘅拳賽，但完全唔知從何入手」
- 「大師姐表面冷靜，但系統負荷接近臨界點，內部正在預警」

**分層渲染對應**：人物 Layer — 表情與姿態設定，非必要動作 hold 死。

---

### Frame 3：佢想要咩？

> 主角呢一刻最想達到嘅目標係？（要具體，唔係「想成功」）

**例子**：
- 「想喺24小時內用 AI 分析對手嘅出拳習慣，整理出一份備戰報告」
- 「想搵出系統過熱嘅根本原因，唔係想換機，係想找到係邊條指令出問題」

**分層渲染對應**：劇本駁口 — 目標 = 每個場景段落嘅推進動力。

---

### Frame 4：障礙係咩？

> 擋住主角嘅係咩？係技術問題、係人、係自己嘅弱點、定係環境？

**例子**：
- 「KO仔完全唔識寫 Prompt，每次問 AI 都係廢話一大堆，得唔到有用答案」
- 「大師姐嘅散熱系統出問題，但如果關機修復就會中斷任務」

**分層渲染對應**：衝突場景 — 觸發動態渲染的時間點。

---

### Frame 5：第一次嘗試

> 主角點樣嘗試解決問題？第一個方法係咩？結果點？

**例子**：
- 「KO仔直接問：『AI你好，我想打贏拳賽，你有冇辦法？』AI 答一大篇廢話。」
- 「大師姐嘗試降頻運行，但精準度下降30%，任務依然無法完成」

**分層渲染對應**：行動序列起點 — T=0 至 T=30s 段落。

---

### Frame 6：轉折點

> 係咩令到事情開始改變？可以係一句說話、一個發現、一個意外、或一個人嘅介入。

**例子**：
- 「大師姐睇著 KO仔嘅破爛 Prompt，嘆氣，直接走過來，改咗三個字」
- 「KO仔突然發現原來對手有一個習慣性嘅左勾拳盲點 — 係 AI 喺第七次回應入面夾帶咗一行數據」

**分層渲染對應**：場景切換點 — 背景換新定格，人物進入新動作序列。

---

### Frame 7：新方法 / 新認知

> 轉折之後，主角做咗咩唔同嘅事？佢學到咗咩，或者用咗咩新方法？

**例子**：
- 「KO仔開始問具體問題：『2024年拳賽數據中，左手出拳率超過60%的對手，右側防守通常係咩漏洞？』AI 直接給出三個可操作建議。」
- 「大師姐決定唔降頻，轉為分佈式處理，將任務拆分成並行執行的小模塊」

**分層渲染對應**：核心學習段落 — 人物動態增加，技術概念植入點。

---

### Frame 8：最高張力時刻

> 故事最緊張、最好笑、或最感動嘅一刻係？（呢一幀係截圖傳播素材）

**例子**：
- 「KO仔睇住大師姐改完嗰三個字，AI 嘅回應從一片廢話變成一份完整備戰報告 — 12秒之內。KO仔的表情：石化。」
- 「大師姐推眼鏡，螢光效果全開，系統溫度顯示 99.9°C，但任務進度顯示 100% — 同一時間發生」

**分層渲染對應**：最高算力需求幀 — 全 Layer 動態，流體力學 + 震動頻率全啟動。

---

### Frame 9：結果呈現

> 最後發生咩事？目標達成咗嗎？成功係完全嘅，定係有代價嘅？

**例子**：
- 「KO仔備戰報告完成。但當佢打開報告，第一頁是：『警告：此數據只能提升準備效率，拳頭嘅力量仍然需要你自己去打。』KO仔看著自己滿是老繭的拳頭，沉默。」
- 「任務完成，系統自動關機冷卻。大師姐消失前說：『下次記得唔好一次過問咁多問題。』」

**分層渲染對應**：結尾定格 — 人物表情 hold，鏡頭慢慢拉遠，背景淡出。

---

### Frame 10：觀眾帶走的一句話

> 如果觀眾睇完之後，只記得一句說話或者一個概念，你希望係咩？

**例子**：
- 「問對問題，比答案更重要。」
- 「AI係工具，但工具係需要主人識用嘅。」
- 「系統過熱唔代表失敗，代表你做緊嘢。」

**分層渲染對應**：字幕 Layer — 最後3秒畫面，標語全螢幕顯示。

## 信息密度要求

填完10條問題之後，每條答案應該包含：

| 元素 | 說明 |
|------|------|
| **具體名詞** | 唔係「某個地方」，係「夜晚12點嘅機房」 |
| **情緒詞** | 唔係「佢不開心」，係「石化、沉默、嘆氣」 |
| **動作詞** | 唔係「佢做咗嘢」，係「推眼鏡、改咗三個字、拳頭握緊」 |
| **因果關係** | 點解呢件事發生？之後點？ |

> **一條好嘅答案 = 一個具體畫面，唔係一個抽象概念。**

---

## 從10條回答到20分鐘視頻

```
Frame 1–2   →  場景建立（T=0–2分鐘）
Frame 3–4   →  衝突引入（T=2–5分鐘）
Frame 5–6   →  嘗試與轉折（T=5–12分鐘）
Frame 7–8   →  高潮段落（T=12–17分鐘）
Frame 9–10  →  結尾與記憶點（T=17–20分鐘）
```

每個 Frame = 一個場景切割點 = 一次分層渲染的狀態更新。  
AI 負責補填中間所有的對白、動作細節、鏡頭語言。

## 算力節省說明

採用分層渲染 + 劇本駁口的方式，20分鐘視頻嘅實際渲染幀數估算：

| 層次 | 策略 | 估算關鍵幀數 |
|------|------|-------------|
| 背景 | 場景切換時重渲，其餘定格 | ~30幀 |
| 人物 | 非必要動作 hold 死，只渲染關鍵動作 | ~200幀 |
| 鏡頭 | Pan/Zoom 作為參數變化，不重渲內容 | — |
| 字幕/特效 | 純文字，極低算力 | — |

**總計 ~500–800 關鍵幀**，等同全幀渲染約50秒的算力，是傳統全幀方案（28,800幀）的 **1/40 成本**。
