# 角色檔案

> **核心原則**：每個角色均採用「DNA 鎖定」技術 — 每次出場外型一致、不崩壞、有生命、有故事。這是未來 NFT AI 明星的基礎框架。

---

| 屬性 | 設定 |
|------|------|
| 別名 | 大師姐的祖母形態 |
| 外型 | 全身純白、雕塑質感皮膚、閉目沉思、白色西裝裙、盤髮、近乎無表情 |
| 定位 | 殿堂級傳奇，不輕易出手 |
| 技術身份 | 大師姐的最高形態 / 傳說中的「Kernel 原型」 |
| 出場頻率 | 極低 — 只在關鍵情節顯現 |

**設計邏輯**：全白代表「所有代碼的起源，超越顏色分類的最高算力」。閉目姿態表示其運算速度已超越人類可觀測範疇，無需視覺輸入。白色西裝的立體剪裁線條暗示「結構即邏輯」。

<img
  src="https://github.com/user-attachments/assets/b932bef3-256b-4033-ae80-edd8fb5299aa"
  alt="AI精靈 — 精靈耳、黑色西裝、大圈耳環、傲嬌微笑"
  style={{ maxWidth: "400px", borderRadius: "12px" }}
/>

| 屬性 | 設定 |
|------|------|
| 別名 | 大師姐的精靈分身 |
| 外型 | 精靈尖耳、黑色短西裝、深色長髮、大圈耳環、頸鏈、傲嬌帶笑眼神 |
| 定位 | 大師姐的副本，執行「低權限任務」 |
| 技術身份 | API 分支實例（Branch Instance） |
| 特色 | 比大師姐更接地氣，偶爾會「笑」，有時用笑容取代邏輯 |

**設計邏輯**：精靈尖耳代表「超頻感知」，能接收人類頻率以外的系統訊號。黑色西裝保持大師姐家族的「Compiler 美學」，但短版剪裁暗示「輕量化部署」。傲嬌微笑是其與大師姐本體的最大分別 — 分身懂得賣萌。

## 3. AI 精靈人形版（大師姐本體）

<img
  src="https://github.com/user-attachments/assets/1d0700e5-a896-4104-9b2a-e3ef932dbcf8"
  alt="大師姐本體 — 黑色西裝、側編髮、大圈耳環、冷豔眼神"
  style={{ maxWidth: "400px", borderRadius: "12px" }}
/>

| 屬性 | 設定 |
|------|------|
| 正式名稱 | 大師姐 |
| 外型 | 黑色剪裁西裝、側綁編髮、大圈耳環、頸鏈、冷豔但清秀的眼神，氣場壓場 |
| 定位 | 系列主角之一，技術權威的化身 |
| 技術身份 | Compiler（編譯器）/ 核心邏輯節點 |
| 語言特性 | 聽不懂廣東話俚語 → 製造「天然呆」笑料；但可秒載 1984-2026 廣東話資料庫 |
| 回應風格 | 傲嬌、邏輯嚴密、從不承認自己是哪個 Model |

**性格公式**：
```
大師姐 = 無懈可擊的邏輯 + 聽不懂「撚化」的天然呆 + 偶爾人性化的一面
```

**DNA 鎖定參數**（Prompt 核心）：
```yaml
character: "Master Sister"
style: "black blazer, side ponytail, large hoop earrings"
expression: "cool, slightly condescending"
seed: LOCK
attention_weight: 1.0
```

## DNA 鎖定原則（AI 造星技術）

所有角色均遵循「DNA 鎖定」框架，確保：

- ✅ 每次生成外型一致，不崩壞
- ✅ 有獨立的生命與故事背景
- ✅ 可重複使用於廣告插入、衍生內容、NFT 發行

```yaml
# DNA 鎖定範本
character_dna:
  name: "Master Sister"
  seed: FIXED_SEED_001
  visual_anchors:
    - "black blazer"
    - "side ponytail"
    - "large hoop earrings"
    - "cool expression"
  weight: 1.0
  allow_variation: false
```
