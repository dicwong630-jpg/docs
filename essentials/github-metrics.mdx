## 什麼是「10k 拉取」？

當你在 GitHub 倉庫的 **Insights → Traffic** 頁面看到「10k pulls（拉取）」時，這個數字代表的是：

> **在過去 14 天內，這個倉庫被透過 `git clone` 或 `git pull` 等操作請求下載的總次數達到 10,000 次。**

這是一個**流量統計數字**，不是限制，也不是你已下載的資料容量。

---

## 三個常見誤解

<AccordionGroup>
  <Accordion title="誤解一：是可拉取次數的限額嗎？">
    **不是。** GitHub 對公開倉庫的 `git clone` / `git pull` 次數沒有硬性上限。10k 只是統計值，不代表你快要「用完」什麼配額。
  </Accordion>

  <Accordion title="誤解二：代表已有 10,000 人下載了嗎？">
    **不完全是。** 一個人可以多次 pull（例如 CI/CD 自動構建每次都會 pull），所以次數 ≠ 獨立下載用戶數。GitHub 在同一頁面也會顯示「unique cloners（獨立來源數）」，那個才更接近實際使用者數量。
  </Accordion>

  <Accordion title="誤解三：會佔用 10k MB 或 GB 的容量嗎？">
    **不是。** 「拉取次數」與「資料傳輸量」是兩回事。容量是看倉庫本身的大小（通常在 **Settings → Danger Zone** 或倉庫首頁的 storage 指標查看），不是拉取次數。
  </Accordion>
</AccordionGroup>

## 數字從哪裡來？

GitHub 會自動記錄每個公開/私有倉庫的 Git 網絡活動，並在 **Insights → Traffic** 頁面展示：

| 欄位 | 說明 |
|------|------|
| **Clones** | `git clone` 的總次數（含機器人、CI/CD） |
| **Unique cloners** | 不重複的來源 IP 數量 |
| **Views** | 網頁瀏覽次數 |
| **Unique visitors** | 不重複訪客數 |

<Note>
  Traffic 數據只保留最近 **14 天**，超過後會自動清除。如需長期追蹤，建議定期手動記錄或使用第三方工具（如 [GitHub Stats](https://github.com/nicedoc/nice-stat)）。
</Note>

## 對你的專案有什麼實際影響？

<CardGroup cols={2}>
  <Card title="熱度指標" icon="chart-line">
    10k 拉取說明你的倉庫有相當高的關注度或被自動化工具頻繁使用，屬於正面訊號。
  </Card>
  <Card title="不影響開發" icon="circle-check">
    這個數字不會限制你的 `git push`、`git pull`、或任何正常開發工作流程。
  </Card>
  <Card title="不佔倉庫容量" icon="hard-drive">
    GitHub 免費帳戶倉庫容量上限為 **1 GB**，拉取次數不會消耗這個配額。
  </Card>
  <Card title="帶寬注意事項" icon="wifi">
    極少數情況下（如大型倉庫被大量鏡像），GitHub 可能聯繫你限制帶寬，但對一般文件/代碼倉庫幾乎不會發生。
  </Card>
</CardGroup>

## 如何查看你的流量數據

<Steps>
  <Step title="進入 Insights 頁面">
    在你的 GitHub 倉庫頁面，點擊頂部導航欄的 **Insights** 標籤。
  </Step>
  <Step title="選擇 Traffic">
    在左側選單中選擇 **Traffic**，即可看到 Clones、Views 等詳細統計。
  </Step>
  <Step title="解讀數據">
    重點看「Unique cloners」而非總 Clones 數，前者更能反映真實的使用者數量。
  </Step>
</Steps>
