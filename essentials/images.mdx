## 圖片

### 使用 Markdown

[Markdown 語法](https://www.markdownguide.org/basic-syntax/#images)可讓你使用以下程式碼新增圖片：

```md
![標題](/path/image.jpg)
```

請注意，圖片檔案大小必須小於 5MB。若超過此限制，建議使用 [Cloudinary](https://cloudinary.com/) 或 [S3](https://aws.amazon.com/s3/) 等服務托管，再以 URL 嵌入。

### 使用嵌入語法

若需要更多圖片自訂彈性，也可以使用[嵌入語法](/writing-content/embed)新增圖片：

```html
<img height="200" src="/path/image.jpg" />
```

## 嵌入內容與 HTML 元素

<iframe
  width="560"
  height="315"
  src="https://www.youtube.com/embed/4KzFe50RQkQ"
  title="YouTube 影片播放器"
  frameBorder="0"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
  style={{ width: '100%', borderRadius: '0.5rem' }}
></iframe>

<br />

<Tip>

Mintlify 支援 [Markdown 中的 HTML 標籤](https://www.markdownguide.org/basic-syntax/#html)。這在你偏好使用 HTML 標籤而非 Markdown 語法時非常有用，也讓你能以無限彈性建立文件。

</Tip>

### iFrame

在文件中載入另一個 HTML 頁面。最常用於嵌入影片。

```html
<iframe src="https://www.youtube.com/embed/4KzFe50RQkQ"> </iframe>
```
