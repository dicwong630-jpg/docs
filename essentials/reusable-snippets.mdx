## 建立自訂片段

**前置條件**：你必須在 `snippets` 目錄中建立片段檔案。

<Note>
  `snippets` 目錄中的任何頁面都會被視為片段，不會獨立渲染為頁面。若要從片段建立獨立頁面，請將片段匯入另一個檔案並以元件形式呼叫。
</Note>

### 預設匯出

1. 在片段檔案中加入你想在多個位置重複使用的內容。你也可以選擇加入變數，在匯入片段時透過 props 填入。

```mdx snippets/my-snippet.mdx
你好！這是我想在各頁面重複使用的內容。今天的關鍵字是 {word}。
```

<Warning>
  你想重複使用的內容必須放置在 `snippets` 目錄中，匯入才能正常運作。
</Warning>

2. 將片段匯入目標檔案。

```mdx destination-file.mdx
---
title: 我的標題
description: 我的說明
---

import MySnippet from '/snippets/path/to/my-snippet.mdx';

## 標題

Lorem impsum dolor sit amet.

<MySnippet word="bananas" />
```

### 可重複使用的變數

1. 從片段檔案匯出變數：

```mdx snippets/path/to/custom-variables.mdx
export const myName = 'my name';

export const myObject = { fruit: 'strawberries' };
```

2. 從目標檔案匯入片段並使用變數：

```mdx destination-file.mdx
---
title: 我的標題
description: 我的說明
---

import { myName, myObject } from '/snippets/path/to/custom-variables.mdx';

你好，我叫 {myName}，我喜歡 {myObject.fruit}。
```

### 可重複使用的元件

1. 在片段檔案中，以箭頭函式的形式匯出元件，並讓它接收 props。

```mdx snippets/custom-component.mdx
export const MyComponent = ({ title }) => (
  <div>
    <h1>{title}</h1>
    <p>... 片段內容 ...</p>
  </div>
);
```

<Warning>
  MDX 無法在箭頭函式的主體內編譯。請盡量使用 HTML 語法，或在需要使用 MDX 時改用預設匯出。
</Warning>

2. 將片段匯入目標檔案並傳入 props

```mdx destination-file.mdx
---
title: 我的標題
description: 我的說明
---

import { MyComponent } from '/snippets/custom-component.mdx';

Lorem ipsum dolor sit amet.

<MyComponent title={'自訂標題'} />
```
