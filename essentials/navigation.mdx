導覽選單是每個網站上的連結清單。

每次新增頁面時，你可能都需要更新 `docs.json`。頁面不會自動出現在導覽中。

## 導覽語法

我們的導覽語法是遞迴式的，意味著你可以建立巢狀導覽群組。頁面名稱不需要包含 `.mdx` 副檔名。

<CodeGroup>

```json 一般導覽
"navigation": {
  "tabs": [
    {
      "tab": "文件",
      "groups": [
        {
          "group": "快速入門",
          "pages": ["quickstart"]
        }
      ]
    }
  ]
}
```

```json 巢狀導覽
"navigation": {
  "tabs": [
    {
      "tab": "文件",
      "groups": [
        {
          "group": "快速入門",
          "pages": [
            "quickstart",
            {
              "group": "巢狀參考頁面",
              "pages": ["nested-reference-page"]
            }
          ]
        }
      ]
    }
  ]
}
```

</CodeGroup>

## 資料夾

只需將 MDX 檔案放入資料夾，並更新 `docs.json` 中的路徑即可。

例如，若要建立位於 `https://yoursite.com/your-folder/your-page` 的頁面，可建立名為 `your-folder` 的資料夾，其中包含名為 `your-page.mdx` 的 MDX 檔案。

<Warning>

除非將其巢狀放置於另一個資料夾內，否則不能使用 `api` 作為資料夾名稱。Mintlify 使用 Next.js，而 Next.js 保留頂層 `api` 資料夾供內部伺服器呼叫使用。`api-reference` 等資料夾名稱是可以接受的。

</Warning>

```json 含資料夾的導覽
"navigation": {
  "tabs": [
    {
      "tab": "文件",
      "groups": [
        {
          "group": "群組名稱",
          "pages": ["your-folder/your-page"]
        }
      ]
    }
  ]
}
```

## 隱藏頁面

未包含在 `docs.json` 中的 MDX 檔案不會出現在側邊欄，但可透過搜尋列或直接連結訪問。
