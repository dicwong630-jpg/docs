## 行內程式碼

若要將 `單字` 或 `片語` 標示為程式碼，請用反引號（`` ` ``）括住它。

```
若要將 `單字` 或 `片語` 標示為程式碼，請用反引號（`）括住它。
```

## 程式碼區塊

使用[圍欄式程式碼區塊](https://www.markdownguide.org/extended-syntax/#fenced-code-blocks)，用三個反引號括住程式碼，並在起始反引號後加上程式語言名稱以啟用語法高亮。你也可以在程式語言名稱後加上程式碼的名稱。

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```
