<Info>
  **前置需求**：
  - Node.js 19 版本或更高版本
  - 包含 `docs.json` 的文件儲存庫
</Info>

依照以下步驟，在你的作業系統上安裝並執行 Mintlify。

<Steps>
<Step title="安裝 Mintlify CLI">

```bash
npm i -g mint
```
</Step>

<Step title="在本機預覽">

進入包含 `docs.json` 的文件目錄，執行以下指令：

```bash
mint dev
```

本機預覽網頁將在 `http://localhost:3000` 啟動。

</Step>
</Steps>

## 自訂連接埠

Mintlify 預設使用 3000 連接埠。你可以使用 `--port` 參數自訂連接埠。例如，若要使用 3333 連接埠，執行此指令：

```bash
mint dev --port 3333
```

若嘗試使用已佔用的連接埠，Mintlify 會自動切換至下一個可用連接埠：

```md
Port 3000 is already in use. Trying 3001 instead.
```

## Mintlify 版本

每個 CLI 版本對應特定的 Mintlify 版本。若本機預覽與正式版本不一致，請更新 CLI：

```bash
mint update
```

## 驗證連結

CLI 可協助驗證文件中的連結。若要找出任何失效連結，請使用以下指令：

```bash
mint broken-links
```

## 程式碼格式化

建議在 IDE 安裝擴充套件以識別和格式化 MDX。如果你使用 VSCode，可以安裝 [MDX VSCode 擴充套件](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx) 進行語法高亮，以及 [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) 進行程式碼格式化。

## 疑難排解

<AccordionGroup>
  <Accordion title='錯誤：無法使用 darwin-arm64 執行環境載入「sharp」模組'>

    這可能是因為 Node 版本過舊。請嘗試以下步驟：
    1. 移除目前安裝的 CLI 版本：`npm remove -g mint`
    2. 升級至 Node v19 或更高版本。
    3. 重新安裝 CLI：`npm i -g mint`
  </Accordion>

  <Accordion title="問題：遇到未知錯誤">
  
    解決方法：進入裝置的根目錄，刪除 `~/.mintlify` 資料夾，然後再次執行 `mint dev`。
  </Accordion>
</AccordionGroup>

想了解最新 CLI 版本的變更？請查看 [CLI 更新記錄](https://www.npmjs.com/package/mintlify?activeTab=versions)。
