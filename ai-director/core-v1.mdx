# AI導演核心系統 v1

> **核心理念**：AI不是自動化工具，而是一塊人與AI共用的黑板。你是創作人，AI是導演。你負責判斷，AI負責執行導演邏輯。

---

## 一、劇本即程式碼（Script as Code）

傳統劇本用自然語言寫，AI理解時有歧義。  
**解決方案**：將劇本結構化，甚至全部用程式碼表示。

```yaml
# 劇本結構範例
scene:
  id: "SC001"
  duration: 30s
  mood: "tense"
  camera:
    type: "close-up"
    subject: "protagonist_face"
  audio:
    bgm: "low_strings"
    sfx: ["heartbeat", "clock_tick"]
  dialogue:
    - speaker: "主角"
      text: "我唔會返去嗰個地方。"
      emotion: "determined"
  cut_to: "SC002"
```

### 為什麼用程式碼做劇本？

| 傳統劇本 | 程式碼劇本 |
|---------|-----------|
| AI靠推測理解意圖 | AI直接讀取結構化指令 |
| 每次生成結果不穩定 | 可重現、可控制 |
| 難以版本管理 | Git追蹤每一個改動 |
| 改一場景影響全局 | 模組化，改一個scene不影響其他 |

## 二、逆向工程訓練法（Reverse Engineering）

**最快訓練AI理解電影的方法：叫AI拆解電影。**

不是叫AI看完整部電影，而是：

1. **選一套經典電影**（例：《教父》、《星球大戰》）
2. **叫AI逆向拆解**：
   - 每個scene的鏡頭語言是什麼？
   - 導演用什麼方法製造張力？
   - 配樂在哪個時間點進入？為什麼？
3. **輸出導演手冊格式**（存入記憶庫）
4. **下次生成視頻時，引用呢份手冊的邏輯**

```markdown
## 逆向工程輸出範例：《教父》開場

鏡頭語言：
- 全黑開場 → 燈光漸亮 → 極近特寫（眼睛）
- 製造神秘感，觀眾主動投入

導演邏輯：
- 先製造問題（黑暗/未知），再給答案
- 對話前，用畫面建立權力關係

配樂規律：
- 重要情緒轉折前3秒，音量下降
- 然後主題旋律進入
```

## 三、AI導演的「出廠邏輯」問題

AI本身有出廠邏輯（default behavior），通常是：
- 生成「合理」的視頻
- 跟隨一般電影語法

**問題**：出廠邏輯 ≠ 你的風格

**解決方案**：用劇本程式碼覆蓋出廠邏輯

> AI冇腦袋，但我哋嘅劇本就係佢必過的那一刻的腦袋。

劇本程式碼 = AI的臨時腦袋，每次生成視頻前先載入。

## 四、低算力長視頻策略

目標：用低算力製作長且可控的視頻

| 策略 | 做法 |
|------|------|
| 分段生成 | 每個scene獨立生成，再剪接 |
| 重用素材 | 相似場景共用背景/角色模型 |
| 靜態鏡頭優先 | 減少複雜動態計算 |
| 文字驅動畫面 | 用字幕/旁白代替複雜動作場景 |
| 關鍵幀控制 | 只渲染關鍵幀，中間用插值 |

## 五、AI翻拍經典大片

**翻拍 ≠ 複製，翻拍 = 還原導演原意 + 加入原本做唔到嘅部分**

許多經典電影受限於：
- 當年的技術限制
- 預算限制
- 物理世界的拍攝條件

用AI翻拍可以：
1. **翻新視覺效果**（4K、AI補幀）
2. **加入刪減場景**（導演原本想要但拍唔到）
3. **改變結局/支線**（用同一套角色，探索另一個可能性）

> 翻新得嘅，一定係一套極品大片。
