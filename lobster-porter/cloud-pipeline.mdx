## 方案二：HuggingFace Spaces 互動 Demo

HuggingFace Spaces 適合建立一個**讓任何人都能操作的網頁介面**，輸入教學主題即可自動生成視頻。

### 步驟 1：建立 Space

1. 前往 [huggingface.co/spaces](https://huggingface.co/spaces)
2. 點擊 **Create new Space**
3. 選擇 **Gradio** 作為 SDK
4. 設定可見性為 **Public**

### 步驟 2：新增 `app.py`

```python
import gradio as gr
import edge_tts
import asyncio
import os

async def generate_audio(text: str, voice: str = "zh-HK-HiuMaanNeural") -> str:
    """使用 Edge-TTS 將文字轉語音"""
    output_path = "/tmp/output.mp3"
    communicate = edge_tts.Communicate(text, voice)
    await communicate.save(output_path)
    return output_path

def tts_interface(text: str, voice: str) -> str:
    audio_path = asyncio.run(generate_audio(text, voice))
    return audio_path

demo = gr.Interface(
    fn=tts_interface,
    inputs=[
        gr.Textbox(label="輸入教學文字", placeholder="例如：今日我哋學習粵語發音..."),
        gr.Dropdown(
            choices=["zh-HK-HiuMaanNeural", "zh-HK-WanLungNeural"],
            value="zh-HK-HiuMaanNeural",
            label="選擇聲線"
        )
    ],
    outputs=gr.Audio(label="生成語音"),
    title="龍蝦搬運工 - TTS 語音生成 Demo",
    description="輸入粵語教學文字，即時生成語音示範"
)

demo.launch()
```

### 步驟 3：新增 `requirements.txt`

```text

```

### 步驟 4：推送至 HuggingFace Spaces

## 方案三：GitHub Actions 自動化排程

將流水線腳本設為每週自動執行，生成新一期教學視頻素材。

新增 `.github/workflows/weekly_pipeline.yml`：

```yaml
name: Weekly Video Pipeline

on:
  schedule:
    - cron: '0 2 * * 1'   # 每週一凌晨 2 時執行
  workflow_dispatch:        # 支援手動觸發

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install dependencies
        run: pip install -r requirements.txt

      - name: Run pipeline
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
        run: python scripts/main_pipeline.py

      - name: Upload output video
        uses: actions/upload-artifact@v4
        with:
          name: output-video
          path: data/output/*.mp4
```

<Warning>
  GitHub Actions 的免費版 runner 沒有 GPU，不適合在 Actions 中執行 Stable Diffusion 本地模型。圖像生成請改用 DALL·E 3 或 Replicate API（按次計費）。
</Warning>
