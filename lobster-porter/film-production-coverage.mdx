## 概覽

以下評估基於 `lobster_porter` v1.0 現有功能，分析在**本地單機環境**下，能涵蓋電影製作流程（劇本開發 → 前期 → 拍攝 → 後製 → 發行）哪些環節，並指出缺口所在。

---

## ✅ 已可支援的製作環節

### 1. 劇本開發（Development）

| 工作項目 | 工具支援 |
|---|---|
| `.fountain` / `.fdx` 腳本批量整理與歸檔 | ✅ `batch_move` + `ExtensionStrategy` |
| 腳本版本備份（複製至 backup/ 資料夾） | ✅ `batch_copy` |
| 按日期歸類草稿版本 | ✅ `DateStrategy` |
| 關鍵字搬運（如 `draft_`、`final_`） | ✅ `KeywordStrategy` |

### 2. 前期製作（Pre-Production）

| 工作項目 | 工具支援 |
|---|---|
| 分鏡（`.psd`）批量分類至 `storyboards/` | ✅ `ExtensionStrategy` |
| 美術資產（`.png` `.jpg`）自動歸類 | ✅ `ExtensionStrategy` |
| AI Prompt 文件（`.json` `.yaml`）整理 | ✅ `ExtensionStrategy` → `prompts/` |
| 製作文件（`.docx` `.pdf`）分類歸檔 | ✅ `ExtensionStrategy` → `documents/` |
| 批量產出資產標籤清單（`tags.json`） | ✅ `batch_tag` + `manifest` |
| 自訂角色/場景/道具資料夾路由 | ✅ `KeywordStrategy` + `ChainStrategy` |

### 3. VFX / 3D 資產前期組織

| 工作項目 | 工具支援 |
|---|---|
| `.blend` `.ma` `.obj` `.fbx` 自動歸至 `vfx/` | ✅ `ExtensionStrategy` |
| `.usd` / `.usda` / `.usdc` USD 管線文件分類 | ✅ `ExtensionStrategy` |

### 4. 操作安全與復原

| 工作項目 | 工具支援 |
|---|---|
| 每步操作寫入 JSON 操作日誌 | ✅ `log_path` 參數 |
| 撤銷最後一步搬運 | ✅ `undo_last()` |
| 撤銷全部操作 | ✅ `undo_all()` |
| 乾跑模式（不實際移動，先預覽） | ✅ `dry_run=True` |
| 人類可讀轉移紀錄 | ✅ `LoggerPlugin` |

---

## ⚠️ 部分支援（需手動輔助）

### 5. 拍攝期（Production）

| 工作項目 | 現況 | 原因 |
|---|---|---|
| 攝影機原檔（`.r3d` `.mxf`）搬移至素材庫 | ⚠️ 可搬但無大檔驗證 | 缺少 MD5/checksum 驗證插件 |
| 每日收材（DIT）日誌自動生成 | ⚠️ 部分（`LoggerPlugin`） | 缺少 DIT 專屬報表格式（CSV/HTML） |
| 聲音檔（`.wav` `.aif`）收集 | ✅ `ExtensionStrategy` → `audio/` | — |
| 多張記憶卡同步收材 | ⚠️ 需多次呼叫 CLI | 缺少批次來源清單（source manifest）支援 |

### 6. 後製（Post-Production）

| 工作項目 | 現況 | 原因 |
|---|---|---|
| 剪輯素材（`.mov` `.mp4`）搬運 | ✅ | — |
| 彩色分級素材輸出整理 | ⚠️ 僅可移動 | 缺少元資料讀取（clip name、timecode） |
| 混音交付包整理 | ⚠️ 可搬但無格式驗證 | 缺少音頻規格檢查插件 |

---

## ❌ 目前尚未涵蓋的環節

### 7. 雲端協作與多用戶同步

| 缺口 | 原因 |
|---|---|
| 多人同時作業、衝突偵測 | 工具設計為本地單機，無網路層 |
| 與 Google Drive / Dropbox / Frame.io 同步 | 缺少雲端 API 整合插件 |
| 遠端審批流程（Review & Approval） | 無工作流狀態機 |

### 8. 資產元資料管理（MAM）

| 缺口 | 原因 |
|---|---|
| 讀取 EXIF / XMP / ID3 元資料 | 缺少元資料解析插件 |
| 視頻 timecode / reel name 提取 | 缺少視頻解碼依賴（如 `ffprobe`） |
| 素材搜尋索引（全文／標籤搜尋） | 缺少資料庫或搜尋引擎後端 |

### 9. 自動化任務編排（「龍蝦大腦」層）

| 缺口 | 原因 |
|---|---|
| 依賴樹執行（A 完成後才觸發 B） | 缺少任務調度器 |
| 異步並行搬運 | 目前為同步單線程 |
| 失敗重試與告警通知 | 缺少錯誤恢復策略 |

### 10. 發行與交付（Distribution）

| 缺口 | 原因 |
|---|---|
| DCP 封裝輸出整理 | 缺少 DCP 規格插件 |
| 版本控制（v1、v2、final、final_v2…） | 缺少語意版本管理 |
| 自動生成交付清單（Delivery List） | 缺少模板化報表輸出 |
