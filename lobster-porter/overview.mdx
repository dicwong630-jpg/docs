## 什麼是龍蝦搬運工？

**龍蝦搬運工（lobster\_porter）** 是一套專為大型協作專案設計的 Python 批量檔案搬運與分類工具。無論是電影製作的資產管理、AI Prompt 素材整理，還是知識庫的資料流轉，龍蝦搬運工都能以可擴展的插件式架構，自動、安全、可撤銷地完成大量重複性操作。

<Info>
**目前版本**：0.9.0（1.0 版本開發中）  
**適用場景**：電影製作資產管理、腳本分鏡整理、AI 提示詞素材庫管理、跨部門大批檔案交付
</Info>

## 快速開始

### 安裝

```bash
# 從本倉庫根目錄安裝（開發模式）
pip install -e .
```

### 三行程式碼上手

```python
from lobster_porter import LobsterPorter

porter = LobsterPorter()
porter.batch_move(["scene_01.pdf", "scene_02.pdf"], destination="劇本/")
```

### CLI 快速示範

```bash
# 批量移動所有 PDF 到「劇本」資料夾
lobster-porter move *.pdf --dest 劇本/

# 試跑（不實際執行）
lobster-porter move *.psd --dest 美術/ --dry-run

# 撤銷最近 3 步
lobster-porter undo --steps 3
```

## 為什麼電影製作需要龍蝦搬運工？

大型電影專案每天產出數百個資產檔案——腳本草稿、分鏡圖、美術稿、音效素材、VFX 輸出、AI 渲染 Prompt……若全靠人手搬運、重命名、分類，不僅耗時且極易出錯。

龍蝦搬運工的設計目標正是解決這個痛點：

| 問題 | 龍蝦搬運工的解決方案 |
|------|---------------------|
| 重複手動搬檔案 | 批量操作 + CLI 一鍵執行 |
| 分類規則多變 | 可組合策略鏈，隨時調整 |
| 誤操作難以復原 | 全程記錄 + 多步驟撤銷 |
| 不同部門格式各異 | 格式分類插件自動路由 |
| 新需求需重寫程式 | 插件系統擴展，不破壞核心 |

## 模組架構

```
lobster_porter/
├── __init__.py          # 套件入口，導出主要類別
├── core.py              # 核心批量操作（move / copy / delete / rename）
├── strategies.py        # 分類策略（FormatStrategy / KeywordStrategy / RegexStrategy）
├── history.py           # 操作歷史記錄與撤銷機制
├── cli.py               # 命令行介面
└── plugins/
    ├── __init__.py
    ├── base.py          # 插件抽象基類
    └── format_classifier.py  # 預設格式分類插件
```
