## 必需功能（1.0 必須完成）

### 🔴 工作流調度大腦（Workflow Orchestrator）

**優先級**：最高  
**預計工作量**：大（3-5 天）

設計並實作 `orchestrator.py` 模組，作為龍蝦搬運工的「大腦」，協調複雜的多步驟搬運工作流：

```python
# 預期使用方式
from lobster_porter.orchestrator import WorkflowOrchestrator

orch = WorkflowOrchestrator()

# 定義工作流：先分類，再搬運，再同步雲端
orch.add_task("classify", strategy=StrategyChain([...]))
orch.add_task("move", depends_on="classify")
orch.add_task("cloud_sync", plugin=CloudSyncPlugin(...), depends_on="move")

orch.run()
```

需要實作的子功能：
- 任務池（Task Queue）管理
- 任務依賴關係（DAG 有向無環圖）
- 異步執行支援
- 進度監控與通知
- 錯誤恢復與重試機制

---

### 🔴 完整測試套件

**優先級**：高  
**預計工作量**：中（2-3 天）

確保核心功能穩定性的必要條件：

- `tests/test_core.py`：覆蓋所有 `LobsterPorter` 方法
- `tests/test_strategies.py`：覆蓋所有分類策略
- `tests/test_history.py`：覆蓋操作記錄與撤銷邏輯
- `tests/test_plugins.py`：覆蓋插件 pre/post_process
- `tests/test_cli.py`：CLI 端到端測試
- 目標覆蓋率：≥ 90%

---

### 🔴 批量刪除安全增強

**優先級**：高  
**預計工作量**：小（0.5-1 天）

現有刪除實作以 `.bak` 備份支援撤銷，但缺少：
- CLI 二次確認提示（`--yes` 旗標繞過）
- 「垃圾桶」模式（使用系統資源回收桶）
- 批量刪除操作報告匯出

---

### 🟡 重命名規則配置化

**優先級**：中  
**預計工作量**：小（0.5-1 天）

目前 `batch_rename` 只接受函式，1.0 版需支援：
- YAML / JSON 配置驅動的重命名規則
- 內建規則：加日期前綴、轉小寫、替換空格、場景編號格式化

## 推薦插件（1.0 建議包含）

### 🟡 索引生成插件（IndexGeneratorPlugin）

搬運完成後自動生成資料夾索引：

```
資產/
├── 劇本/ (12 個檔案)
├── 美術/ (45 個檔案)
├── 音效/ (8 個檔案)
└── index.json  ← 自動生成
```

---

### 🟡 格式轉換插件（ConvertPlugin）

搬運時自動執行輕量格式轉換：
- `.docx` → `.pdf`（使用 `pandoc`）
- 圖片尺寸調整（使用 `Pillow`）
- 音訊格式統一（使用 `pydub`）

---

### 🟢 雲端同步插件（CloudSyncPlugin）

搬運完成後同步到雲端：
- Amazon S3
- Google Cloud Storage
- Dropbox / OneDrive

---

### 🟢 Slack / Teams 通知插件

批量操作完成後自動推送通知到協作平台。
