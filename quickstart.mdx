## 三步驟快速上手

在本機啟動你的文件網站，並完成第一次自訂設定。

### 第一步：設定本機環境

<AccordionGroup>
  <Accordion icon="copy" title="將文件庫複製到本機">
    在上線流程中，如果你尚未建立 GitHub 儲存庫，系統會為你建立一個包含文件內容的儲存庫。你可以在 [管理後台](https://dashboard.mintlify.com) 找到該儲存庫的連結。

    若要將儲存庫複製到本機以便編輯和預覽文件，請參閱 GitHub 文件中的 [複製儲存庫](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository) 教學。
  </Accordion>
  <Accordion icon="rectangle-terminal" title="啟動預覽伺服器">
    1. 安裝 Mintlify CLI：`npm i -g mint`
    2. 進入文件目錄並執行：`mint dev`
    3. 開啟 `http://localhost:3000` 即可即時預覽你的文件！

    <Tip>你在編輯檔案時，預覽畫面會自動更新。</Tip>
  </Accordion>
</AccordionGroup>

### 第二步：部署你的變更

<AccordionGroup>
  <Accordion icon="github" title="安裝 GitHub 應用程式">
    從 [管理後台](https://dashboard.mintlify.com/settings/organization/github-app) 安裝 Mintlify GitHub 應用程式。

    我們的 GitHub 應用程式會自動將你的變更部署到文件網站，無需手動管理部署流程。
  </Accordion>
  <Accordion icon="palette" title="更新網站名稱與色彩">
    作為第一次修改，讓我們更新文件網站的名稱和色彩。

    1. 在編輯器中開啟 `docs.json`。
    2. 將 `"name"` 欄位改為你的專案名稱。
    3. 更新 `"colors"` 以符合你的品牌色彩。
    4. 儲存後即可在 `http://localhost:3000` 即時看到變更。

    <Tip>嘗試更改主色調，立即看到明顯的差異！</Tip>
  </Accordion>
</AccordionGroup>

### 第三步：正式上線

<Accordion icon="rocket" title="發布你的文件">
  1. Commit 並 push 你的變更。
  2. 你的文件將在片刻後更新並正式上線！
</Accordion>
