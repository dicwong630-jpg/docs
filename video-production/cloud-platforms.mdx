## 背景與目標

為實現「**ko仔語言教學10**」系列 YouTube 視頻的完整製作流程，本頁比較市面上主流可用雲端平台，涵蓋：

- 教學腳本自動生成
- 批量素材搬運與分類（龍蝦搬運工 / lobster_porter）
- 影音內容組裝與格式轉換
- 多人協作與版本管理
- 無需本地大型部署的全雲端流水線

## 3. 依龍蝦搬運工架構推薦三大方案

### 方案 A：GitHub Actions + HuggingFace API（最輕量，零成本起步）

```
lobster_porter repo
       │
       ├─ push / cron trigger
       │
       ▼
GitHub Actions Workflow
  ├─ 呼叫 HuggingFace Whisper API → 生成字幕 (.srt)
  ├─ 呼叫 NLLB 翻譯 API → 粵語/普通話/英語字幕
  ├─ FFmpeg 合成字幕 + 素材影片 → MP4
  └─ 上傳至 GitHub Release / Artifact
```

**優點**：完全免費、流程在 repo 內透明可見、Copilot 可直接協助撰寫 Workflow YAML  
**限制**：Actions 執行時間限制（6小時/job），大型影片需切割

---

### 方案 B：GitHub + Kaggle + HuggingFace（PoC 到持續優化）

```
lobster_porter repo
       │
       ├─ 素材元資料 / 腳本 JSON 推送
       │
       ▼
Kaggle Scheduled Notebook
  ├─ 讀取腳本 JSON → 批量呼叫 HuggingFace TTS 生成配音
  ├─ 批量字幕生成（Whisper large-v3）
  ├─ MoviePy / FFmpeg 影片組裝
  └─ 輸出存至 Kaggle Dataset → 手動下載或 API 取回
```

**優點**：免費 GPU、排程自動執行、適合多集批量製作  
**限制**：Kaggle 儲存空間有限，需定期清理；協作介面較簡陋

---

### 方案 C：GitHub + AWS S3 + MediaConvert（生產級全自動管線）

```
lobster_porter repo
       │
       ├─ GitHub Actions 觸發
       │
       ▼
AWS S3 素材桶
  ├─ Lambda 函數自動觸發（素材上傳事件）
  │   ├─ 呼叫 SageMaker Endpoint（字幕/分類 AI）
  │   └─ 提交 MediaConvert 轉碼作業
  │
  ▼
S3 輸出桶（成品 MP4）
  └─ CloudFront CDN 發布 / 直接上傳 YouTube API
```

**優點**：完全自動化、可擴展至任意規模、MediaConvert 支援 HDR/4K/字幕嵌入  
**限制**：需 AWS 帳戶、初期設定成本與學習曲線較高

## 4. 三階段建議路線

<Steps>

<Step title="初發表 / PoC 階段（第 1–4 週）">

**目標**：製作第一支 3 分鐘 ko仔語言教學10 樣本影片，驗證流程可行

**推薦方案**：方案 A（GitHub Actions + HuggingFace API）

**具體步驟**：

1. 在 lobster_porter repo 新增 `.github/workflows/video-build.yml`
2. 準備一段原始素材影片（MP4）和腳本文字（JSON/TXT）上傳至 repo
3. Workflow 自動執行：
   - 呼叫 HuggingFace Whisper 生成字幕
   - FFmpeg 合成字幕與影片
   - 上傳成品至 GitHub Releases
4. 在 README 展示成果，收集社群初步反饋

**所需設定**：
```yaml
# .github/workflows/video-build.yml
name: Build Teaching Video
on:
  push:
    paths:
      - 'scripts/**'
      - 'assets/**'
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install FFmpeg
        run: sudo apt-get install -y ffmpeg
      - name: Generate subtitles via HuggingFace
        env:
          HF_TOKEN: ${{ secrets.HF_TOKEN }}
        run: python scripts/generate_subtitles.py
      - name: Assemble video
        run: python scripts/assemble_video.py
      - name: Upload artifact
        uses: actions/upload-artifact@v4
        with:
          name: teaching-video
          path: output/*.mp4
```

</Step>

<Step title="持續優化 / 多用戶協作階段（第 1–3 個月）">

**目標**：批量製作多集教學影片，引入協作者分工，建立可重複的製作流程

**推薦方案**：方案 B（GitHub + Kaggle + HuggingFace）

**具體步驟**：

1. 建立標準化腳本 JSON 格式（每集素材、旁白、字幕時間軸）
2. Kaggle Notebook 定時（每週一次）批量處理：
   - 讀取新增腳本 → 生成配音（TTS）→ 合成影片
3. GitHub Issues 作為任務看板，協作者認領不同教學集製作
4. Branch Protection：main 分支需 PR review 才可合併成片素材
5. 使用 HuggingFace Spaces 部署字幕預覽 / 腳本生成 Demo

**協作角色分工**：

| 角色 | 負責 | 工具 |
|------|------|------|
| 專案負責人 | 最終審核、合併、發布決策 | GitHub（Admin） |
| 腳本撰寫者 | 撰寫教學腳本 JSON | GitHub Issues / PR |
| 技術維護者 | 維護 Workflow、修復 Bug | GitHub Actions |
| 影片審核 | 測試成品影片 | GitHub Releases |

</Step>

<Step title="龐大內容生成階段（3 個月後）">

**目標**：自動化生產 ko仔語言教學10 完整系列（50+ 集），支援多語言字幕與高清輸出

**推薦方案**：方案 C（GitHub + AWS S3 + MediaConvert）

**具體步驟**：

1. 將所有素材遷移至 AWS S3，設定版本控制與生命週期規則
2. 部署 Lambda 函數處理上傳事件，自動排隊 MediaConvert 作業
3. SageMaker Batch Transform 批量生成多語言字幕（粵語→普通話→英語）
4. MediaConvert 輸出多解析度版本（720p / 1080p）並嵌入字幕
5. 設定 YouTube Data API 自動上傳與排程發布
6. GitHub Actions 作為流程觸發入口，保持 repo 為唯一事實來源

**成本估算**（每月 10 支 10 分鐘影片）：

| 服務 | 用量 | 估算費用 |
|------|------|----------|
| S3 儲存 | 50 GB | ~USD 1.15 |
| MediaConvert | 100 分鐘 | ~USD 1.50 |
| SageMaker Batch | 10 作業 | ~USD 3–5 |
| Lambda | 100 次呼叫 | < USD 0.01 |
| **合計** | | **~USD 6–8 / 月** |

</Step>

</Steps>

## 6. 給外行創作者的快速起步建議

<Tip>
不需要懂所有技術細節。從最小可行方案開始，每一步都有 Copilot 協助撰寫腳本和 Workflow。
</Tip>

**立即可做的三件事**：

1. **在 lobster_porter repo 新增 `scripts/` 目錄**，放入第一集教學腳本（純文字或 JSON）
2. **申請 HuggingFace 免費帳戶**，取得 API Token，加入 GitHub repo Secrets
3. **讓 Copilot 幫你生成第一個 `video-build.yml`** Workflow，觸發自動字幕生成

完成這三步，你就已經有了一條從「文字腳本」到「帶字幕影片」的全雲端自動化管線。

<Note>
所有平台選擇均以「**不依賴本地高性能機器**、**開源透明**、**可逐步升級**」為原則，完全符合龍蝦搬運工專案的現有架構與你的初心——讓最好的技術人人可用。
</Note>
