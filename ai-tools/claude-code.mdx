設定 Claude Code，協助你撰寫和維護 Mintlify 文件。

## 前置需求

- 有效的 Claude 訂閱（Pro、Max 或 API 存取權）

## 設定步驟

<Steps>
<Step title="安裝 Claude Code">
  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
</Step>

<Step title="安裝 Mintlify 技能">
  在文件目錄中執行：

  ```bash
  npx skills add https://mintlify.com/docs
  ```

  這會將 Mintlify 的元件參考、撰寫標準和工作流程指引提供給 Claude Code 使用。
</Step>

<Step title="自訂專案說明">
  編輯專案根目錄中的 `AGENTS.md`，加入專案專屬的術語、樣式偏好和內容邊界。
</Step>

<Step title="開始使用 Claude Code 撰寫">
  ```bash
  claude
  ```
</Step>
</Steps>
