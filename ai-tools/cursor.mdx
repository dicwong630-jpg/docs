設定 Cursor，協助你撰寫和維護 Mintlify 文件。

## 前置需求

- 已安裝 Cursor 編輯器

## 設定步驟

<Steps>
<Step title="在 Cursor 中開啟文件目錄">
  開啟文件儲存庫的根目錄，即包含 `docs.json` 的位置。
</Step>

<Step title="安裝 Mintlify 技能">
  在整合終端機中執行：

  ```bash
  npx skills add https://mintlify.com/docs
  ```

  這會將 Mintlify 的元件參考、撰寫標準和工作流程指引提供給 Cursor 使用。
</Step>

<Step title="自訂專案說明">
  編輯專案根目錄中的 `AGENTS.md`，加入專案專屬的術語、樣式偏好和內容邊界。
</Step>

<Step title="開始使用 Cursor 撰寫">
  開啟檔案，使用 Cursor 的 AI 功能起草和編輯文件。
</Step>
</Steps>
